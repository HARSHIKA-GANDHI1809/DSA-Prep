# Remove Elements:-
##Problem:-
  Given an array of sixe n and a value to be removed from that array
## Example:-
 arr[]={3,2,2,3} val= 3
 output={2,2}
## Approach:-
 Will take an int k and iterate an array
 if the element at current position is equal to value then will not add that element in nums[k]
 else will continue for other elements
 ## Complexity:-
   Time complexity:-O(n)
   Space Complexity:-O(1)
