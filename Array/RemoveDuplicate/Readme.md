
#Remove Duplicate:-
##Problem:-
  Given an array we have to remove duplicates from that array.
##Example:-
  array[]={1,2,2,3,5,5} 
  Output:-{1,2,3,5}
##Approach:-
  2pointer approach
    will take 2 pointer and iterate it to an array 
    If duplicates doesn't occur then continue a[i]=a[j] && i++
    else just continue
##Complexity:-
   Time complexity:-O(n)
   Space Complexity:-O(1)
